# Android Auto Browser

Android WebView browser for using a normal browser experience in the car (Car Browser build).

## Build

Requirements: Android SDK, JDK 21. Create `local.properties` with `sdk.dir` pointing at your Android SDK.

```bash
./gradlew assembleDebug
```

Debug APK: `app/build/renamedApks/debug/CarBrowser-<version>_debug.apk`
